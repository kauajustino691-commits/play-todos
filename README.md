# ♿ PLAY/TODOS — Laboratório de Acessibilidade Digital

**Tecnologia acessível é tecnologia para todos!**

O PLAY/TODOS é um projeto acadêmico desenvolvido para demonstrar, de forma interativa, como a acessibilidade digital pode tornar sites e aplicativos mais inclusivos.

O projeto utiliza um player de vídeo como exemplo para apresentar recursos que facilitam a navegação e a utilização de interfaces por pessoas com diferentes necessidades, incluindo usuários de leitores de tela e navegação por teclado.

## 🎯 Objetivo

Demonstrar como pequenas mudanças no desenvolvimento de interfaces podem melhorar a experiência digital, promovendo inclusão, autonomia e acessibilidade.

## 🚀 Funcionalidades

- **Player de vídeo acessível:** permite iniciar e pausar a reprodução, informando o estado atual.
- **Alto contraste:** modifica as cores da interface para melhorar a leitura.
- **Redução de movimento:** diminui animações e transições da página.
- **Navegação por teclado:** permite navegar pelos elementos utilizando a tecla Tab e ativar controles com Enter ou Espaço.
- **Acessibilidade mobile:** apresenta exemplos de propriedades de acessibilidade utilizadas no React Native.

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- JavaScript
- React Native (exemplo de acessibilidade mobile)

## 🖥️ Demonstração do projeto

O PLAY/TODOS permite testar recursos de acessibilidade diretamente na interface, proporcionando uma experiência prática de aprendizado.
